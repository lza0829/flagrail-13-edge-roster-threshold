## 边缘名册门槛（已实现）

同票三件套：**名册（边缘名册表）/ 确认集（回读证）/ 放量（放量门表）**。门槛只谈齐套计数，与「偏差隔离」无关——偏差回读不计入已确认，也不改门槛口径。

- **全员口径**：门槛 = 名册人数，缺一则放量失败。
- **多数口径**：门槛 = 上取整(名册人数 / 2)，达标即放量，核证列出缺席边缘。
- 2/3 确认时两口径成败相反：全员失败（缺 1 人）、多数成功（门槛 2）。
- 名册变更 / 策略切换 / 放量都在 `BEGIN IMMEDIATE` 写事务内，与回读并发取锁失败即 fail-close（503），门槛在同一事务快照内瞬时一致、不漂移。
- 放量无论成败都落「门槛核证」（名册 / 已确认 / 门槛 / 缺席 / valid）；成功另落放量门与放量命运（命运账，含缺席清单与门槛算法），禁止只返回 JSON。
- 路由：`/api/边缘名册`、`/api/门槛策略`、`/api/放量`、`/api/门槛核证`、`/api/门槛视图`、`/api/放量门`；自动化见 `backend/tests/`。
